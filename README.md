# All in One

รวมผลงานทุกชิ้นของลิกไว้ที่เดียว — หาง่าย ไม่กระจัดกระจาย

**เว็บสารบัญ:** https://zetxero-main.github.io/all-in-one/

## โครงสร้าง

| โฟลเดอร์ / ไฟล์ | เก็บอะไร |
|---|---|
| `index.html` | เว็บสารบัญ รวมทุกโปรเจกต์ ค้นหาและกรองตามหมวดได้ |
| `notes/` | โน้ต สรุปบทเรียน ความรู้ที่จดไว้ |
| `ideas/` | ไอเดียโปรเจกต์ที่ยังไม่ได้ทำ |
| `files/` | เอกสาร ไฟล์งาน (xlsx, pdf, รูป) ที่อยากเก็บไว้ที่เดียว |

โค้ดแต่ละโปรเจกต์ยังอยู่ในรีโพของมันเหมือนเดิม — รีโพนี้เป็น "ศูนย์กลาง" ที่ชี้ไปหาทุกอัน

## เพิ่มโปรเจกต์ใหม่

เปิด `index.html` แล้วเพิ่มหนึ่งบรรทัดใน array `PROJECTS`:

```js
{name:'ชื่อโปรเจกต์', repo:'ชื่อรีโพ', web:true, cat:'การเงิน', desc:'อธิบายสั้นๆ'},
```

| ช่อง | ความหมาย |
|---|---|
| `name` | ชื่อที่แสดงบนการ์ด |
| `repo` | ชื่อรีโพบน GitHub (เว้นว่าง `''` ถ้ายังไม่ได้อัปขึ้น) — จะมีปุ่ม "GitHub" ให้อัตโนมัติ |
| `web` | ใส่ `web:true` ถ้ารีโพนั้นเปิด GitHub Pages แล้ว — ปุ่ม "เปิดเว็บ" จะลิงก์ไป `https://zetxero-main.github.io/<repo>/` ให้เอง (ไม่ต้องพิมพ์ลิงก์) |
| `site` | ใช้เฉพาะเมื่อเว็บอยู่ที่ลิงก์อื่น (เช่นโดเมนของตัวเอง, Firebase) — ถ้าใส่ จะใช้ลิงก์นี้แทนลิงก์จาก `web` |
| `cat` | หมวดหมู่ ต้องตรงกับใน `CATS` |
| `desc` | คำอธิบายสั้นๆ |

ตัวอย่างเว็บที่อยู่ลิงก์อื่น:

```js
{name:'ชื่อโปรเจกต์', repo:'ชื่อรีโพ', site:'https://example.com/', cat:'อื่นๆ', desc:'อธิบายสั้นๆ'},
```

หมวดที่มี: การเงิน, งานร้าน, POS, Vending, เรียนรู้, AI & เครื่องมือ, อื่นๆ

## เว็บ (GitHub Pages)

เปิด GitHub Pages ไว้แล้วที่ https://zetxero-main.github.io/all-in-one/ — แก้ `index.html` แล้ว commit ขึ้น main เว็บจะอัปเดตเองภายใน 1–2 นาที

## โปรเจกต์ที่ยังไม่ขึ้น GitHub

ในเว็บจะมีป้าย "ยังไม่ขึ้น GitHub" — ทยอยอัปทีละอันจาก Termux/Acode แล้วใส่ชื่อรีโพในช่อง `repo`
